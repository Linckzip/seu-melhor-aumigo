# Seu Melhor Aumigo

## Descrição do projeto

O Seu Melhor Aumigo é um projeto de site para uma ONG fictícia de proteção animal. O objetivo é apresentar a organização, seus projetos e disponibilizar um formulário para cadastro de voluntários.

O projeto foi desenvolvido como uma SPA (Single Page Application), permitindo a navegação entre as diferentes seções sem a necessidade de carregar várias páginas HTML.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Git
- GitHub

## Estrutura do projeto

O projeto está organizado em pastas para facilitar a localização e manutenção dos arquivos:

- `html/` – arquivo principal da aplicação
- `css/` – arquivo de estilos
- `js/` – arquivos JavaScript e seus módulos
- `images/` – imagens utilizadas no projeto

## Como executar o projeto

Para executar o projeto localmente, abra a pasta no Visual Studio Code e utilize a extensão Live Server para iniciar o servidor local e visualizar a aplicação no navegador.

## Funcionalidades

O site possui:

- Seção Sobre nós
- Seção Projetos
- Cadastro de voluntários
- Validação do formulário
- Modal de confirmação
- Armazenamento dos dados do cadastro no navegador

## Controle de versões

O projeto utiliza Git e GitHub para controle de versões e organização do desenvolvimento.

As alterações são organizadas por branches e commits, seguindo um padrão de mensagens semânticas.
